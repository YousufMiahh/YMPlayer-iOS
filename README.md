# YM Player for iPhone & iPad

Native iOS / iPadOS (SwiftUI + VLC) player for Xtream Codes IPTV — the iPhone and iPad version of YM Player,
laid out like the Android phone app.

- Home, Live TV, Movies, Series, Downloads and Search along the bottom
- Turns sideways when you start watching, with touch controls: tap for controls, double-tap left / right to
  skip −5 s / +10 s, swipe up / down on Live TV to change channel, pinch to fill the screen
- VLC plays everything (live TS / HLS, MKV, MP4), with every audio and subtitle track
- Netflix UK Top 10, Continue Watching, your Queue, "Because you watched", favourites, Skip Intro and Next Episode
- TV guide, downloads (also in the Files app), AirPlay (MKV files are repackaged on the phone for the Apple TV) and Chromecast, multiple accounts, light / dark theme
- Syncs favourites, Continue Watching and more with the Fire TV, Android, Mac and Samsung apps

## Install

The app isn't signed with a paid Apple developer account, so install the `.ipa` from the
[latest release](https://github.com/YousufMiahh/YMPlayer-iOS/releases/latest) with
**Sideloadly** or **AltStore** and your Apple ID. With a free Apple ID the app has to be re-signed every 7 days
(AltStore does this automatically).

Requires iOS / iPadOS 16 or newer. Every push to `main` builds a new release with GitHub Actions.
